# AB-650 lab files

These files support the AB-650 labs. In the hosted lab environment, this folder is the **AllFiles (F:)** drive on **SEA-DEV1** and **SEA-DEV2**. The drive is read-only, so copy a file to **Documents** before you edit it. If you aren't using the hosted lab environment, download the files you need from this folder.

| Folder | File | Used in |
| --- | --- | --- |
| `Lab03` | `new-hires.csv` | Lab 3, Exercise 1: bulk-create new-hire accounts |
| `Lab05` | `Lab5-SIT-Match.txt`, `Lab5-SIT-NearMiss.txt` | Lab 5, Exercise 1: test the custom sensitive information type |
| `Lab05` | `Lab5-DLP-Worksheet.txt` | Lab 5, Exercise 2: record DLP, retention, and DSPM results |
| `Lab06` | `17-cowork-consumption-practice.csv` | Lab 6, Exercise 3: interpret a sample Cowork consumption case |
| `ClassActivities` | `21-agent-governance-case-practice.csv`, `22-copilot-usage-practice.csv`, `23-cost-reconciliation-practice.csv` | Instructor-led class activities for Lab 7 topics |

> **Practice data only.** The CSV files are fictional sample cases. They aren't alerts, audit events, usage reports, or billing records from your tenant. Each row is labeled **Practice data** in its `DataLabel` or `Provenance` column, and the consumption and cost files add **(not paid usage)**. Don't search a portal for the sample users, events, or charges, and don't combine sample figures with live tenant results.
