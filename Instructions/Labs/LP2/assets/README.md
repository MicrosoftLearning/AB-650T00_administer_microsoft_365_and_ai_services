# LP2 lab assets: sample case files

These files are sample evidence used by the LP2 lab guides. They aren't live results from your tenant, so don't search a portal for their names, IDs, or events. Files that you open or upload inside the lab VMs are in the `Allfiles` folder, which is the **AllFiles (F:)** drive in the hosted lab environment.

| File | Used in | Purpose |
| --- | --- | --- |
| `04-signin-evidence.md` | Lab 4, Exercise 2 | Report-only sign-in results, a risky sign-in, a What If result, and the emergency-access safeguard |
| `04-threat-evidence.md` | Lab 4, Exercise 4 | Simulation report, email entity timeline, alert-to-incident correlation, and a pending automated investigation and response recommendation |
| `05-dlp-dspm-evidence.md` | Lab 5, Exercise 2 | A DLP alert in a Defender XDR incident and a DSPM oversharing assessment case |
